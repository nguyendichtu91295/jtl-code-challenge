# Frontend project guidance

Read and follow these shared rules before working in `senior-frontend-engineer/`:

- [AI workflow](.ai/ai_workflow.md): planning, task creation, execution, and validation.
- [Coding conventions](.ai/coding_convention.md): structure, state ownership, types, and error handling.
- [Deployment rules](.ai/deployment.md): release preparation, publishing, and verification when deployment is requested.

This folder is the project root and write boundary for all work. Keep application code, configuration, plans, tasks, deployment files, and AI journey evidence here.

Read `instructions.md` and the repository's `../README.md` before planning or implementing the frontend challenge. The parent README is shared reference material; keep changes inside this frontend folder. Challenge requirements take precedence over generic examples in these shared rules.

Preserve the required `ai-journey/` evidence as work proceeds, including plans, key prompts, tools used, and the user's decisions. Plans and task records created by the local workflow should be included or linked there when preparing the submission.
